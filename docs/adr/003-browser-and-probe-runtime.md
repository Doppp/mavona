# ADR 003: Native browser provisioning and isolated Ruby syntax

Status: accepted for implementation; full product/platform matrices remain incomplete.

The application remains Bun/TypeScript/OpenTUI. A versioned, copied Ruby probe parses explicit source strings with Prism 1.8.1 under Ruby 4.0.6 without gems, application cwd, Ruby preloads or target boot. No parser fallback silently promotes unavailable facts. Small fixture tests observe approximately 40–90 ms extraction paths on Darwin arm64; these are test timings, not a representative performance claim. Instruction ancestry and digest caches stay in TypeScript. Broader parity and parser performance review remain required.

Playwright and playwright-core 1.63.0 (Apache-2.0, maintained Microsoft upstream) are pinned exactly. `pngjs` 7.0.0 is MIT, dependency-free at runtime, with a stable older release; decoded-pixel/metadata/bounds tests justify its limited current use. Its type package is development-only. Native engine packages are separate, explicit downloads; they are never silently installed by startup. Engine execution and PNG comparison passed compiled macOS arm64 spikes for Chromium, Firefox and WebKit. This does not establish other-platform support.

The standalone `app install` command uses the same version-pinned registry exported by Playwright's own install CLI. Initial isolated-cache installation failed because Playwright forks a JavaScript download entry while Bun's compiled executable dispatches its own main. The one-line tracked playwright-core patch selects a dedicated internal marker only under the build-time `MAVONA_COMPILED` constant. The application accepts this marker only with a live IPC channel and invokes the upstream download worker; ordinary CLI entry cannot invoke the worker. Development execution retains the original JavaScript entry. This is a narrow packaging correction, not a new downloader. Re-audit the patch and declarations on every Playwright upgrade.

After the correction, the macOS arm64 standalone binary downloaded Firefox 155.0/revision1543 and FFmpeg1011 into an empty isolated cache, from `/tmp` with PATH `/usr/bin:/bin`, then used that Firefox for a real assertion and masked capture. Browser archives came from Playwright's configured HTTPS hosts. The product installer never runs sudo or installs OS packages. Complete clean-install platform evidence and signed release artifacts remain outstanding.

The inspection boundary uses Playwright plus an owned origin-policy proxy, fresh observations, bounded semantic actions, isolated authentication references, managed captures/downloads and explicit flow-digest approval. Raw trace/video is withheld until required sanitization is complete. Operation recordings are labelled separately; they do not satisfy the raw trace/video contract. Captures and model-proposed assertions cannot establish functional correctness.
